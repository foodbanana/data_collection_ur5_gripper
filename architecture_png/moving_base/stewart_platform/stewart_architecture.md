# Stewart 플랫폼 위 UR5 (움직이는 베이스: 6 축 사인파, sim 전용)

공통 구조는 `../moving_base_architecture.md`. 여기는 Stewart 전용. 근거: `isaacsim/config/base_stewart.yaml`, `scene_stewart.yaml`, `moving_base.StewartBase`, `SineTrajectory`, `design_stewart.py`, `build_stewart_usd.py`, `docs/moving_base.md` 8 장.

상자 안에는 한글, ASCII 만 쓴다 (한글 = 2 칸으로 맞춤). 한글 고정폭 글꼴 (예: D2Coding) 에서 테두리가 맞게 보인다.
(*) = 고정 베이스 (`../fixed_base/fixed_base_architecture.md`) 와 달라지거나 새로 생긴 곳.

```text
┌─ 크기 설계 -> USD 생성 (실물 없음) ──────────────────────────────────────────────────┐

└──────────────────────────────────────────────────────────────────────────────────────┘
          |
          v
┌─ Stewart USD ──────────────────────────────────────────────────────┐
│ isaacsim/assets/bases/stewart/stewart.usda                         │
│   base_plate : 아랫판 (반지름 0.9, 두께 0.05), 정적 충돌           │
│   top_plate  : 윗판 (반지름 0.7, 두께 0.05), kinematic 강체 + 충돌 │
│      imu_link : 윗판 아랫면 가운데 (물리 없음)                     │

│ 윗판 translate + orient = 궤적 자세 (부모가 강체가 아니라 tensor view 유지) │

│   L_i = | c + R P_i - B_i |   (P_i 윗판 부착점, B_i 아랫판 부착점)          │

```

## 움직임 - 6 축 사인파 (SineTrajectory)

```text
┌─ base_stewart.yaml motion ────────────────────────────────────────────────────────────┐
│ q_k(t) = e(t) * s * A_k * sin(w_k t + phi_k),   k = x, y, z, roll, pitch, yaw         │
│   e(t) = 10u^3 - 15u^4 + 6u^5,  u = t / 5 s  (5 차 램프: 위치, 속도, 가속도가 이어짐) │
│   w_k = Omega_k * U(0.7, 1.3),   phi_k = U(0, 2 pi)   (리셋마다 새 seed)              │
│   Omega = (0.9, 0.5, 0.9, 0.5, 0.9, 0.2) rad/s  (연구실 이전 연구 값)                 │
│ 윗판 자세: 회전 중심 = 윗판 윗면 가운데 (= 로봇 base 자리)                            │
│   c = (q_x, q_y, 1.0 + q_z),   R = Rz(yaw) Ry(pitch) Rx(roll)                         │
└───────────────────────────────────────────────────────────────────────────────────────┘

┌─ 프리셋 (진폭 = s x big) ───────────────────────────────────────────────────────────────────────────┐
│ 프리셋   s     x / y / z [m]           roll / pitch / yaw [rad]   잡기 시간 비율   수집             │
│ big      1.0   0.15 / 0.10 / 0.15       0.105 / 0.105 / 0.053      4.5 %            보류            │
│ mid      0.5   0.075 / 0.05 / 0.075     0.053 / 0.053 / 0.026      26 %             일부            │
│ small    0.25  0.0375 / 0.025 / 0.0375  0.026 / 0.026 / 0.013      94 %             주력            │
│ static   0     0                        0                          -                난이도 1 단계   │
│ lab      1.0   0.30 / 0.10 / 0.30       0.105 / 0.209 / 0.053      -                비교용 (수집 X) │
└─────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 배치

```text
┌─ scene_stewart.yaml ────────────────────────────────────────────────┐
│ UR5 마운트: 윗판 회전 중심 (0, 0, 0), yaw 0 -> 로봇 base 높이 1.0 m │
│ 에피소드 시작 = 가운데 자세 (램프가 0 에서 시작) = 움직임 가운데    │
│ 드론 기준 위치 = 로봇 base + (0.60, 0, 0.738)  (world z 약 1.74 m)  │
│ PX4 이륙 지점 = (1.2, 0.15) 바닥 (아랫판 반지름 0.9 밖)             │
│ third view = world 고정 (높이만 이 씬 base 에 맞춤)                 │
│ UR5 연결: root_joint body0 = top_plate + excludeFromArticulation    │
└─────────────────────────────────────────────────────────────────────┘
```

